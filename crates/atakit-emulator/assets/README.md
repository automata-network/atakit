# Emulator assets

The embedded runtime bytecode is built from the Solidity sources in
[`../contracts`](../contracts). The DCAP mock supports V1 and V2 (compact output
format 2.1); the TPM mock retains TPM parsing while skipping hardware signatures.
These mocks replace hardware verification backends only, not Registry contracts.

To rebuild, install Foundry, Solidity 0.8.27, `jq`, `xxd`, and `shasum`, then run:

```bash
crates/atakit-emulator/scripts/refresh-mocks.sh \
  --contracts /path/to/tee-workload-attestation
```

The companion checkout supplies Solidity interfaces and TPM parsing libraries,
not mock source files. Use revision `0e0991b656fd7568ebfff9a9cf3554899695073a`
with its dependencies initialized. Compilation runs offline in a temporary
project and leaves that checkout unchanged. Generated bytecode and source/runtime
SHA-256 hashes are written here. `contracts/MockTpmAttestation.sol` was copied
from that revision with its original license header.

The embedded-bytecode regression test in `tests/nested_fork.rs` checks V1/V2
compatibility, quote/body commitments, and malformed quote rejection using Anvil.

`gcp-ak-certs.json` and `gcp-ak-pub.hex` contain public certificate/public-key
fixture data from `atakit-dev/crates/automata-cvm-agent/src/mock/mock_device_data.json`.
They contain no private AK key. Software session and TPM delegation keys are
generated independently at runtime.
