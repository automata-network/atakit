# atakit-cvm-types

`atakit-cvm-types` contains chain-independent Rust types defined by the Atakit
specifications. It does not contain contract bindings, a provider, a
signer, or Solidity ABI encoding.

See the [workload specification](../../docs/atakit-workload-toml-spec.md) and
[runtime configuration](../../docs/runtime-configuration.md).
