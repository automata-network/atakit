# atakit-cvm-types

`atakit-cvm-types` contains chain-independent Rust types defined by the atakit
suite specifications. It does not contain contract bindings, a provider, a
signer, or Solidity ABI encoding.

The canonical specifications live in the `docs/specs/` directory of the
[`atakit-suite`](https://github.com/automata-network/atakit-suite) repository.
